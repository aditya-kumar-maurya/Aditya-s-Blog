My Journey into Java, Python and GenAI

Notes from a B.Tech CSE student building real projects

Posted by Aditya Kumar Maurya on August 05, 2026

I'm Aditya Kumar Maurya, a Computer Science undergraduate from Ballia, Uttar Pradesh, pursuing my B.Tech at AKTU. This blog is where I share what I'm learning as I build my path toward becoming a software developer and GenAI engineer.

My core strength has always been Java. I built an Automated Teller Machine Simulation and a Banking System Application, both using Java OOP concepts with JDBC for database connectivity, and clean HTML/CSS interfaces on top.

During my internship at Coding Samurai in August-September 2025, I got hands-on experience with real-world Java application development, debugging, and problem solving.

Expanding into Python and GenAI

Lately I've been deepening my Python skills alongside my Java background, and exploring Artificial Intelligence and Generative AI. I hold a certification in Introduction to Generative AI Studio from Google Cloud, an AI certification from IIT Kanpur, and a Core Java Programming certification from Infosys Springboard.

Every project I build, whether in Java or Python, teaches me something new about how software really works under the hood.

What's Next

I'm continuing to sharpen my skills in Data Structures and Algorithms, SQL, and Computer Networks, while working toward my goal of becoming a GenAI Engineer. Follow along as I document my learning, my projects, and everything in between.
